💳 Credit Card Fraud Detection Dashboard

A Machine Learning-based Credit Card Fraud Detection project that analyzes transaction data and identifies potentially fraudulent transactions through an interactive dashboard built with Streamlit.

📌 Project Overview

This project uses Machine Learning to detect suspicious credit card transactions. It provides an interactive dashboard where users can upload transaction data, analyze fraud patterns, and explore prediction results through visualizations and performance metrics.

🎯 Objectives

- Detect potentially fraudulent transactions using Machine Learning.
- Analyze transaction patterns.
- Visualize fraud-related insights through an interactive dashboard.
- Evaluate model performance using multiple classification metrics.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly
- Machine Learning

📊 Dashboard Features

- Interactive fraud detection dashboard.
- Upload transaction datasets for analysis.
- Fraud prediction results.
- Key performance indicator (KPI) cards.
- Interactive visualizations.
- Transaction analysis.
- Model performance evaluation.
- ROC-AUC, Precision, Recall and F1-score metrics.

🚀 How to Run the Project

1. Clone the repository

git clone https://github.com/KartikSanga9/Credit-Card-Fraud-Detection.git

2. Navigate to the project folder

cd Credit-Card-Fraud-Detection

3. Install dependencies

pip install streamlit pandas numpy scikit-learn plotly

4. Run the dashboard

streamlit run Banking_Fraud_Detection/app.py
